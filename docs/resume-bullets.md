# Resume Bullets

- **Architected and developed a full-stack campus management platform** serving multiple modules (Events, Clubs, Help Desk) using Spring Boot 3, Java 21, and React with Vite.
- **Implemented advanced event waitlist and capacity logic** using transactional boundaries in Spring Data JPA, ensuring ACID compliance during high-concurrency event registrations.
- **Secured API endpoints** with stateless JWT authentication, Role-Based Access Control (RBAC), and BCrypt password hashing via Spring Security.
- **Optimized frontend delivery** by migrating to Tailwind v4 and implementing route-level code splitting with React Suspense, reducing the initial JavaScript payload by 85% (from 671KB to 97KB).
